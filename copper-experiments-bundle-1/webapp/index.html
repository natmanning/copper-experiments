Copper Porphyry Halo Prospect Map

Trained on 5 known porphyry Cu-Mo(-Au) deposits with Pb-Zn-Ag halos (Bingham Canyon, Mineral Park, Santa Rita/Chino, Yerington, Sierrita/ Twin Buttes), scored against LGND earth-observation embeddings (Sentinel/NAIP-derived, centroid_difference ranking). Not drill-ready — a reconnaissance aid.

Scope, honestly: this run covers the continental US only — the only LGND collection this account currently has that covers the training sites. A global public Sentinel-2 embedding archive exists at source.coop/clay/lgnd-embeddings for genuinely worldwide search, but this environment's network policy currently blocks source.coop — enabling it is the next step to actually go global.
